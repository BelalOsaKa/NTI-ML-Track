# 🤖 NTI Machine Learning & Data Analysis Track

My projects, labs and assignments from the **NTI Machine Learning & Data Analysis** track, from pandas basics to end-to-end ML projects and deployment.

## 🏆 Graduation project
**[BusinessLaunch AI](https://github.com/BelalOsaKa/BusinessLaunchAI)** answers "Should I open a restaurant or café here?" It combines regression, NLP, clustering and a Monte Carlo financial simulator on Yelp data in an interactive Streamlit app.

## ▶️ Running a notebook
```bash

cd NTI-ML-Track
pip install pandas numpy matplotlib seaborn scikit-learn jupyter

```
