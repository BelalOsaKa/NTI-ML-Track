# Ames Housing Price Prediction
An end-to-end regression project on the Ames, Iowa housing dataset (2,930 homes, 80 features):

1. Dataset understanding and manual EDA
2. Automated EDA with ydata-profiling (`ames_housing_profile.html`)
3. Preprocessing plan and a train / validation / test split
4. Model development and hyperparameter tuning
5. Evaluation, model comparison and interpretation
6. Final report export (`ames_housing_final_report.pdf`)

| File | Content |
|---|---|
| `ames_Housing_projectt.ipynb` | Final, complete version |
| `ames_Housing_project.ipynb` | Earlier version |
| `AmesHousing.csv`, `data_description.txt` | Data and data dictionary |
