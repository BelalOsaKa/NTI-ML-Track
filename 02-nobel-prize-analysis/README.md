# Nobel Prize Data Analysis
Exploratory data analysis of every Nobel Prize winner: data understanding, data-quality checks and preprocessing, then 12 visual insights. They cover the gender gap and how women's share changed by decade, top countries, categories over time, age at award, prize amounts and the organisations behind laureates.

| File | Content |
|---|---|
| `belal_nobel_assignment.ipynb` | Part 1: pandas practice questions |
| `belal_nobel_assign2.ipynb` | Part 2: full analysis with 12 insights |
| `nobel_figures/` | Exported charts |
| `*.py` | Helper scripts used to build and verify the notebook |

**Tools:** pandas, NumPy, Matplotlib, seaborn
