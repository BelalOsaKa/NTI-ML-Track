# MAGIC Gamma Telescope: Logistic Regression
Classifying gamma-ray signals versus hadron background in the UCI MAGIC Gamma Telescope dataset (19,020 events, 10 image features) with Logistic Regression. Evaluated with a confusion matrix and classification metrics.

**Data:** `magic04.data` (description in `magic04.names`) · **Tools:** pandas, scikit-learn, seaborn
